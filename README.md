# 算力图解书

面向工业视觉项目的四章交互式算力解读网站。

在线访问：https://compute-power-guide.cdav32bkk8wx.chatgpt.site

## 当前内容

1. 场景任务量与算力需求计算
2. 配置适配与实测性能判断
3. IPC 组成、资源消耗与排队
4. 现场验证、尾延迟与放行证据

教学示例中的性能数据不代表真实硬件测试结果。

## 文件与本地查看

- `dist/index.html`：完整静态网页，包含样式、图解和交互脚本，无需编译。
- `.openai/hosting.json`：原 Sites 项目标识和静态目录配置，不包含凭据。

下载仓库后可直接用浏览器打开 `dist/index.html`。也可在仓库目录运行：

```sh
python -m http.server 8000 --directory dist
```

然后访问 http://localhost:8000 。
